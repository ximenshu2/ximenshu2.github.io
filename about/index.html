关于本站

我们为什么做这个网络隐私检测指南

本站用于整理 VPN、IP、DNS、WebRTC 与网络隐私相关的检测方法， 帮助用户理解检测结果代表什么，以及哪些结果不能被过度解读。

最后更新：2026-08-17
本站原则： 尽量把产品官方说明、技术资料和实际检测结果分开。 一次测试只能反映特定设备、浏览器、网络和时间下的情况， 不应被描述为永久或绝对的安全证明。

本站主要提供什么

  • VPN 连接前后的公网 IP 对照方法。
  • DNS 解析路径与常见误判说明。
  • WebRTC 中公网 IP、内网 IP 与 mDNS 的区别。
  • VPN 能解决和不能解决的隐私问题。
  • 修改设置后的复测方法。

我们如何更新内容

页面中的“最后更新”日期只在内容发生实质修改时调整。 如果只是重新部署网站、调整样式或进行不影响内容含义的技术修改， 不会把文章日期自动刷新为当天。

浏览器、操作系统、VPN 客户端和网络协议都可能发生变化。 因此，涉及具体产品功能或浏览器行为时，应同时核对相关官方资料。

官方说明与检测结果有什么区别

服务商官网可以说明产品当前宣称支持哪些平台、协议或隐私功能， 但官方说明不能替代实际环境中的检测。

同样，本站的测试结果和判断方法也只能说明特定条件下观察到的网络信号， 不能证明某个服务在所有设备、所有网络和所有时间都具有相同表现。

关于第三方产品链接

本站部分内容可能链接到第三方产品或服务商的官方网站， 主要用于方便用户核对当前产品说明、平台支持、隐私政策或服务条款。

涉及第三方产品时，应把服务商自己的声明与独立检测结果分开理解。 产品功能、价格、隐私政策和服务条款可能随时间变化， 具体信息应以第三方官方网站当前公布的内容为准。

检测结果的边界

网络隐私检测通常只能观察当前请求暴露出来的信息。 检测网站本身也会接触访问请求所必需的网络信息， 因此不应向未知检测网站上传账号资料、完整 IP 截图或其他敏感信息。

VPN 也不能替代账号安全、MFA、系统更新、恶意软件防护、 浏览器隐私设置或应用权限管理。

发现内容有问题怎么办

如果某项浏览器行为、协议说明或第三方产品信息已经发生变化， 应优先依据浏览器厂商、标准组织、监管机构或服务商当前官方资料进行核对， 并在确认内容需要修改后更新对应文章。
